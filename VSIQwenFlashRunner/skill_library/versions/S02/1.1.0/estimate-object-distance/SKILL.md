# 对象间绝对距离估计

## 方法

1. 从题面提取两个对象的角色和消歧描述，明确要求的是对象之间的最近距离，不是相机到对象的距离，也不是默认的质心距离。
2. 确定两个具体实例。若同类对象有多个，先利用题面修饰、共现结构和可见帧完成消歧，再优先向距离工具传入明确的 `obj_id`。
3. 米制几何获准时，调用 `object_distance_m(obj_a, obj_b)`。核对返回的 `a`、`b` 是否对应题面实例，并检查 `distance_m`、`definition`、`n_valid_points` 和 `degradation_flags`。
4. `distance_m` 已经是米，直接作为米制候选，不要再次乘尺度。`distance_normalized` 只用于审计或一致性检查，不能在没有有效尺度时自行换算成米。
5. 检查最近表面是否受遮挡、点集污染、局部可见或重复实例影响。当前工具使用稳健低分位点云表面距离代理，不能宣称恢复了不可见完整表面的精确真值。
6. 工具测量不可用时，从多个原图视角比较对象边界、相邻关系和深度线索，并结合有依据的参照尺寸估计米制量级；最后输出最有依据的有限非负数值。

## 分支与检查

- 缺少有效尺度、三维几何或对象绑定时，不得调用米制距离工具，也不能用视觉猜测补造尺度权限。
- 工具失败、无效数值、空点集或结果失效不能解释为零距离；应改用视觉估计路径。
- 已是米的 `distance_m` 不再换算；只有题面明确要求其他单位时才按题意转换。
- 同一对象被同时解析为 `obj_a` 和 `obj_b` 表示绑定错误，必须重新消歧。
- 视觉参照物应处于相近深度并使用合理尺寸范围，不能把不同深度的像素比例直接当作米制比例。
- 提交前检查对象身份、距离口径、单位和依据类型，避免将视觉估计记录成工具测量。
