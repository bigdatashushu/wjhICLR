# 对象间相对距离推理

## 方法

1. 从题面提取参照对象、候选类别和原始选项映射。参照对象是题目点名的对象，不是相机；候选列表必须覆盖全部选项。
2. 建立参照实例与候选实例。若同类参照对象有多个，先根据题面描述、共现结构和可见帧确定具体实例，并优先向距离工具传入 `obj_id`；不要依赖类别名命中多个实例时的默认顺序。候选类别可以有多个实例，按题意比较其中距离参照对象最近的实例。
3. 几何工具获准时，调用 `relative_distance_rank(reference, candidate_categories)`。核对返回的 `reference` 是否对应题面参照实例，并检查 `ranking`、`closest_category`、`categories_without_detection`、`definition` 和 `degradation_flags`。
4. 使用同一次调用产生的 `distance_normalized` 排序。相对排序中的统一尺度会约掉，不需要米制尺度；不要为了得到米数而补造尺度，也不要改用相机深度或二维像素间隔代替对象间距离。
5. 重点核查会改变前两名的错误绑定、点集污染、遮挡、重复实例和候选覆盖缺口。需要补充证据时，优先检查与这些歧义直接相关的冻结帧或候选类别。
6. 将最近类别映射回当前题目的合法选项。提交前再次检查参照身份、候选覆盖、距离定义和选项映射。

## 分支与检查

- `categories_without_detection` 中的类别是未知，不是无限远，也不能从候选集合中静默删除；可用时补检相关类别，否则在最终比较中保留覆盖不完整这一不确定性。
- 工具未获准、执行失败、返回空排序或结果失效时，不得把失败解释为零距离或场景中没有对象。改用原图中的共享结构、遮挡、相对深度和局部布局进行视觉比较。
- 明确当前结果使用的是稳健低分位表面距离代理，不要将它改称精确最近点距离、质心距离或官方三维真值。
- 图像二维间隔只能作为视觉线索；候选处于不同深度或视角畸变明显时，不能直接按像素间隔排序。
- 同类别候选按最近实例聚合；同类别参照对象存在多个实例时必须先消歧，两种多实例规则不能混为一谈。
- 最终答案必须来自当前选项映射，并与实际使用的有效工具结果或视觉依据一致。
