# VSIQwenFlashRunner 开发约束

本目录服务于 VSI-Bench 1000 题的 Qwen Flash 实验，当前使用独立的
`prepared_cache/vsibench-m4-success-g1m1-1000-seed137-metric-r02` 数据包。
用户要求进一步优化实验的新逻辑全部放在本目录，外层代码已被其他数据集和
实验配置使用。

- VSI1000 后续优化所需的源码、脚本、配置、测试和说明均在本目录修改。
- 外层 `src/`、`scripts/`、`configs/`、`skill_library/` 及其他 runner
  保持只读；只有用户明确授权外层变更时才修改。
- 需要修改已有实现时，将相关模块及必要依赖复制到本目录，并确保本目录入口
  实际使用本地实现。禁止通过 monkey patch、写入共享模块或修改外层配置实现优化。
- 只读复用外层实现时明确依赖路径；会影响实验行为的本地模块应核对加载来源，
  避免本地和外层同名模块被静默混用。
- 使用 `configs/vsi_m4_1000.json` 维护本目录的独立实验配置。
  在用户提出具体优化要求前，保留原实验参数和数据划分。
- 当前题单按已授权的 20 组替换保留 980 题，使用 1000 题、
  300 训练/700 测试、160 场景和原 seed 137；两种角色均覆盖 160 场景。
  原始题型（含方向难度）、source split 和角色联合配额保持不变。
  全部题目使用已核验的 metric/g1m1 资产及对应 Skill 槽位。
  场景能力覆盖 24 个槽位；米制工具仍只对三类测量题授权。
  旧的 19 槽合同保留只读加载兼容，新绑定派生写入每轮 runs 内的缓存。
  保持原始 source split 及标签访问来源。测试题不用于 Skill 修订或候选选择。
- 原数据包、已发布输入和冻结实验产物只读。新缓存放在 `prepared_cache/`，
  新实验产物放在 `runs/`，每轮使用独立目录并记录源码、配置和输入身份。
- 在线求解保持参考答案不可见；凭据只从运行环境读取，不写入源码、配置或日志。

本目录独立入口为 `run.py` / `experiment.sh`。九阶段编排、fit-set 执行、
主求解器及 Skill 演化主干已经迁移；来源记录在 `migration.json`。

开发态由本地 `skill3d` 包优先加载本地模块，再明确查找外层共享包。
新增本地子包需参照已有 `__init__.py` 保留该规则，使用 `--show-source`
核对实际加载路径。

正式运行通过 `vsi_runner_source.py` 合并并冻结本地实现与共享依赖，
所有阶段和子进程使用该轮 `code/source/`。运行身份以逐文件内容哈希为准，
保留真实 Git 来源；不因迁移而自动提交。续跑只接管本目录生成的源码快照，
保持已冻结配置、输入、预算和阶段回执身份。
