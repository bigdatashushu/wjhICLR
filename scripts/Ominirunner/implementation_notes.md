2026-11-03。原版本及已有全部更改已提交为 `b7adc9a4a2a7f5e5972d5bc0e42313b714140739`，Mac、GitHub 与服务器 main 已同步。随后在 `omni-seven-fixes-20261103` 实现本版，新增修改尚未提交或推送。

修改依据为 [七项建议及轨迹证据](file:///Users/bytedance/wangjh/omni3d-trajectory-review-20261103/modification_recommendations.md)，对应已审阅的 20 题、120 轮与 r05 冻结源码。本版不读取真实标签，不运行模型／GPU，不改写旧实验、MMSI 归档或公共预计算组件。

| 修改 | 实现与验收 | 原轨迹依据 |
|---|---|---|
| 1. 公开答案标签 | answer_contract.py 提取结构化 options、题内枚举与是非标签，生成 O1/O2/...；worker 输出原标签并保留 raw_answer。非法标签返回字段反馈，score.py 原样保留 | 417 选择电视却输出 `the tv`，严格匹配失分 |
| 2. 错点复核与替换 | wrong／wrong target → resample，保留 raw_decision；replaces 引用当前交付测量。成功替换后旧值持续排除，新点下一请求复核；旧点退出待办 | 10 的非法 wrong；81 错目标被全标 usable |
| 3. 工具比较 | tool_comparison 保存有界两侧表达式、绑定、比较符与答案映射；宿主重算关系，校验可见、usable、单位、参照与标签。支持六个关系符及三路比较 | 21、417 的工具类别推断没有可绑定的比较合同 |
| 4. 坐标与实际表面 | 深度显示加原像素网格；原图／crop 的 pixel 或 normalized 坐标由宿主映射，保留图像哈希与最终原像素。采样 intended_targets 与复核 observed_surfaces 分记，pair 分别复核两端 | 411 多次点到错误物体，375 坐标越界 |
| 5. 任务量、单位与完整端点 | 公开任务规格约束 camera Z、尺寸、比例、物体间距、步行和碰撞；表达式验证单位，米制必须有题内公开尺度锚。完整尺寸的实际表面与目标／极值匹配且 visible，选用邻点须复核该精确 sample_xy | 190、222 墙面／中段冒充完整尺寸；411 Z 比例冒充步行；21 相对 Z 冒充米 |
| 6. 候选来历与实体范围 | 保留候选 ID、类别审核与通过状态、实际回执 identity/hash；NMS 未记录时标未知。重叠仅作待查线索，不自动合并；计数必须提供 RGB 实体 include/exclude 与关联，体积估计必须固定对象范围和形状 | 106 未确认遥控器被按重叠合并；81 同椅重复／局部框 IoU 0.769；49、31 范围变化 |
| 7. 有效进展与精度 | 下一轮显示未解决点和固定长度进展计数；完整 ID 留宿主。相同数据重复调用不算新证据。汇总输入／输出 token、替换测量、内容新增且 usable 的替换、复核变化和无进展轮次，保持原始数值精度 | 375、411、222 消耗集中；21 无新测量长推理；411 重复低精度答案 |

实际 worker、审计重放、报告与轨迹使用同一状态和进展定义。`evidence_activity.usable_novel_replacements` 只统计成功返回、内容新增、最终 usable 的替换；这是可观察的合同统计。表面命中与实例判断仍由同一个作答模型声明，不能将此统计解释为真实目标命中率。

数值及比较证据分层记录 `arithmetic`、`task_unit_contract` 和 `surface_identity`；`independent_visual_geometry=false`。新增合同可以拒绝错单位、错依赖与矛盾声明，但同模型同时把墙面误写为目标表面时，宿主不能独立识别。步行、碰撞、方向推断所需的地面／运动几何未由现有四工具提供，因此不得使用这些工具数值声明相应计算；仍可提交有简短依据的 RGB 判断。

本轮缓存路径没有可核验的 NMS 保留／抑制记录，也未取得本轮实际 Jev 身份回执。包装器如实暴露已有类别审核及未知 NMS，不补造链路或重新计算 201 图。高 IoU 可以表示重复框、部件或独立邻近实体，后续合并需明确 RGB 关系。未展示的候选 ID 不能用于实体清单。

协议升级为 `omni-static-depth-versus-official-direct/10`、worker `/10`、tools `/5`、review `/4`、evidence `/5`、packing `/6`。新冻结源码要求包含 answer_contract.py、coordinates.py、instances.py、progress.py；旧冻结运行不能直接换用新代码。

离线验证使用合成 RGB／几何、临时目录和模拟客户端，清除继承的服务凭据与端点变量，禁用 GPU。专项测试禁止网络 transport，覆盖公开标签、错点排除／替换、所有比较符、错参考／错单位／未交付／非法表达式、归一化与局部边界、完整端点与遮挡、比例精度、重复候选及范围、重复数据进展，以及真实 worker 与重放篡改检测。原有 64 项离线 episode 检查继续验证沙箱、阶段、80 条测量积压、精度和服务不重试。复测调度离线检查另验证 20 路准入、活跃槽位拒绝切换、历史记录保留与收费扣除。
