## 2. 模块级落点（§3 / §4）

### M1 Adapter（§4 M1）
- 32 帧均匀采样：`np.linspace(0, n-1, 32).round()`，**唯一性显式校验**；不足 32 帧 = 输入合法性硬失败（不再重复末帧补齐）。
- `FrameSet.frame_set_hash = sha256(json(frame_ids, sort_keys=True))`；`adapters/vsibench_loader.build_episode` 与 `adapters/episode_source.load_vsi_bench_items` 均挂到 `VSIBenchEpisode.frame_set`。
- 不做题目感知选帧（不引入 CLIP/SigLIP、不维护双帧集），理由写入模块 docstring。

### M2 Input Gate（§4 M2）
- 双判据（绝对下界 + episode 中位×0.35）保留；新增逐帧 `degradation_flags` 与 `quality_weight`。
- **`drop_and_refill` 动作已从 schema 与实现中移除**（`InputGateVerdict.action ∈ {proceed, fallback_2d_only, unanswerable}`）。
- 唯一 hard fail 通道 = 输入合法性（空帧/尺寸非法/损坏/帧数 <32）。
- M2 权重并入 route 判定（合成路径 `synthetic.build_scene_state(input_quality_weight=...)`；真实路径经 M4 质量分与门控）。

### M3 重建（§4 M3）
- `reconstruction/ba_route.py`：两条 route 封装 + PoC 探测（`probe_pycolmap` 的 `hasattr` + 两参签名）、正方形预处理前提（`square_preprocess_wh`，官方 `track_predict` 断言 H==W）、`min_inlier_per_frame=64` 策略（`run_inlier_policy`）、失败回退时 `g5=NaN` 且用 `depth_conf/point_conf` 作**弱代理**（`weak_g5_proxy`，明确不称 BA 结果）。
- `vggt_runner.run_vggt`：`recon_method ∈ {vggt, vggt_ba}`（BA 未生效时**不得**标 vggt_ba）；落 `frame_ids/source_frame_indices/timestamps/frame_set_hash`；G5 标量仅在 BA 真跑通时填。
- 术语纠正（VGGT = Visual Geometry Grounded Transformer；"VGGT feed-forward"；c2w=inv(extrin)）写入模块 docstring。

### M4 质量门禁（§4 M4，方案 X/Y）
- P1（`reconstruction/run.py:run_jobs`）在重建时调用 `run_vggt(compute_quality=True)` → G1–G11 随 artifact 落盘（**方案 X**）。
- P2（`online/runner._scene_from_artifact`）读到 `quality_status != "computed"` 时才实算，并**原子写回** artifact JSON（**方案 Y**：`write_artifact_json` 临时文件 + `replace`）。
- `SceneState` 携带 `available_artifacts` 与运行时 `artifact`/`quality` 只读引用（不序列化，无独立 quality 副本）。
- 真实数据验证（无 GPU）：对首次真实 E2E 产物 `data/reconstructions/real_e2e/41069043_artifact.json`（旧数据 NaN 占位）执行 M4 → `quality_status: not_computed → computed`，`overall_quality=0.8393`，route `fallback_2d_only`（因 `scale_confidence=low, scale_ci=3.41m`），`g5=None`（未跑 BA，不伪造）。

### M5 对象绑定（§4 M5）
- D-1 协议已在实现中：4 探测帧（`0, n/3, 2n/3, n-1`）→ 每 (帧, 框) 独立 `obj_id` → SAM2 传播 → 3D 质心去重（阈值 = 深度中位 ×0.15）。
- 本次新增 **双向传播**：`_propagate_bidirectional`（正向 + `reverse=True` 逆向补齐提示帧之前）；逆向不可用时只保留正向（不阻断）。
- 坐标换算统一走 §9 层（`coords.vlm_box_to_pixels` / `coords.resize_mask_nearest`）。

### M6 Tool Registry（§4 M6）
- `ToolSpec.requires_artifacts` 为**必填**（无默认值），产物名受 `KNOWN_ARTIFACTS` 校验；7 个 Tool 全部显式声明。
- `REGISTRY.docs(route=...)` 静态裁剪 + `docs_header(route, available)`（prompt 头部显式写 route 与可用产物）；`docs(full_3d) ⊇ docs(fallback_2d_only) ⊇ docs(unanswerable)` 有属性测试。
- `ROUTE_ARTIFACTS` 单一事实源被 `tools`、`routing.skill_retriever`、`reconstruction_gate.scene_state` 共用。
- 恢复层（回灌一次 → 裁剪 prompt 一次 → abstain）实现于 `online/runner._regenerate_after_contract`，由 `enable_tool_contract_replay` 控制（默认关：`[Conditional Go]`，回灌修复率 ≥50% 才启用）。

### M7 Task Classifier + Skill Retriever（§4 M7）
- 硬过滤谓词由 `scale_known` 升级为 `metric_scale_usable()` = `scale_known ∧ scale_confidence ∈ {medium, high}`（`None` 视为不可用）。
- Skill 的 `requires_artifacts` 支持别名归一（`point_map→point_cloud`、`c2w→poses`、`depth_maps→depth`…），与 Tool 产物词汇表对齐。

### M8 Synthesizer（§4 M8）
- 多模态 messages（文本 + 32 帧 JPEG data URL）；`max_images` 小于帧数**直接报错**（不静默丢帧）。
- `tools=REGISTRY.docs(route=...)`；prompt 含 "当前 route=…，可用产物=…"，并要求无法获得时 abstain 而非猜测。
- 回灌模式下 messages 追加 `assistant(上一轮 program)` + `user(裁剪 traceback + 可用产物清单)`。

### M9/M10（§4 M9/M10）
- 回灌后重生成必须重过 AST 白名单（`_regenerate_after_contract` 内显式 `ast_guard`）。
- kernel：`ToolContractError` 家族 → `error_code="tool_contract"` + `answer_untrusted=True`；命中即清空答案槽；`reset_user_namespace()` 用于重执行前重注入（SpatialClaw §E.3）。

### M11/M12（§4 M11/M12）
- M11 未改（确定性 numpy/scipy/open3d 硬门）。
- M12 改为官方 MRA（见硬约束 27）；非法值记 0；`MRA@10%` 仅作附录诊断（`mra_at_10pct`）。

### §6.1 在线服务纪律
- `synthesis/vllm_client.py`：endpoint 归一化（`/v1/v1` 折叠，C-1）、`health_check`（`GET /health`）、
  `list_models`（模型名核对）、`check_service`/`probe_service`（启动前预检）、
  `ServiceUnavailable` 异常族 —— 服务故障记 **`service_unavailable`**（不是 crash、不是静默降级），
  runner 据此把 episode 记 `unavailable`。

### §8.3 主表口径
- `evaluation/multi_seed_aggregator.py:macro_average_over_tasks` / `format_main_table_row`：
  4 NA(MRA) + 4 MCA(Acc) 共 8 任务**简单算术平均 ×100**（无加权，按官方 Table 10 版式）；
  `object_rel_direction` 的 easy/medium/hard **先等权聚合**再进 8 任务平均，同时保留三档明细；
  未覆盖任务不计入平均（`missing_tasks` 显式列出，不臆造 0）。
- runner 的 per-task 聚合新增 `levels` 档位明细；`online/eval.py` 打印该行。

### 关于 §2.2「P2 不重跑 M2」的口径说明
- G1–G11 在 `quality_status=="computed"` 时 **零重算**（方案 X，P1 已落盘）；
- 在线 FSM 的 M2 门禁照常运行（纯 CPU 被动观测，产生逐帧 flag/weight 供 route 判定与归因），
  这是 §3 M2「在线 FSM 顺序不变」的要求；两者不冲突：重算禁令针对 G1–G11，不针对 M2 观测本身。

### M13 / M21（§4 M13、§7）
- `ProgramExecutionTrace` 新增 `tool_contract` 枚举与 `answer_untrusted`；`ToolResult` 新增 `error_code / missing_artifacts / available_artifacts`。
- `RunManifest` 新增 `vllm_model / n_frames / max_pixels / max_model_len / vllm_endpoints / frame_set_hash / ba_enabled / scale_source`，由 `online/eval.py:_write_manifest` 写入（帧集一致时记该 hash，多 scene 时记 `multi:<digest>` + 去重个数）。
