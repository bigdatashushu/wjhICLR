# 跨帧对象去重计数

## 方法

1. 从题面提取目标类别、空间范围和包含或排除关系。区分整体与部件，不要把同一物体的附件重复计数。
2. 查看原图并整理目标候选。`list_objects(category_filter)` 返回对象记录列表，其中每项包含 `obj_id`、`category_name`、`visible_frames`、`track_id` 和 `duplicate_suspect`；记录条数只是候选数，不是最终答案。
3. 建立题内实例表，记录每个候选的共现帧、轨迹、相邻结构和外观。跨帧合并需要多个身份线索支持；同一帧同时出现的同款物体应保留为不同实例，不能只因外观相似就合并。
4. `count_objects(category_name)` 获准时，读取 `count`、`n_records`、`n_distinct_tracks`、`n_geometric_merges`、`n_without_track`、`duplicate_suspect` 和 `evidence_degraded`。工具先把相同非空 track 的记录合为一组，无 track 的记录各自一组，再按组间几何重合去重；没有点云的组仍计一次。`count = n_distinct_tracks - n_geometric_merges`，不等于原始记录条数。将结果与实例表和原图覆盖情况交叉核对。
5. 若遗漏可能改变计数，可针对目标类别和相关冻结帧调用 `detect_objects`。区分 `status="fault"`、`status="empty"` 和 `status="ok"`，并检查 `error` 中的部分帧故障。新检出是并入本题清单的二维候选，没有自动获得三维绑定或跨帧 track；同一物体的多帧检出不能直接累加，也不能直接加到旧 `count` 上。结合共现、外观与位置重新核对身份和重复关系。
6. 解决工具结果与视觉观察的具体冲突，选择最有依据的非负整数。计数为零必须由有效观察或健康空检出支持。

## 分支与检查

- `count_objects` 不可用或证据降级时，根据原图和实例表继续计数，但不要把候选记录条数直接当作答案。
- 检测服务故障、工具未运行或无效返回不能推导零；健康空检出只能证明指定帧未检出，不能证明整个视频绝无该对象。
- 遮挡后重现、轨迹碎裂和重复检测可能高估计数；有限帧覆盖和完全不可见实例可能低估计数。
- 几何位置只能在对应证据和绑定有效时辅助去重，不能把二维检测框伪装成三维实例。
- 提交前检查同一实体跨帧只计一次、同款多实例未被误合并，并确认结果是当前题目要求的非负整数。
