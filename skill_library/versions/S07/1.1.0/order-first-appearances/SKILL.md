# 目标类别首次出现顺序判断

## 方法

1. 从题面列出所有待排序类别和完整选项序列，使用冻结 FrameSet 的帧槽位顺序 0..31；不要按文件名、界面布局或未提供的视频帧重排时间。
2. 查看原图并用 `list_objects(category_filter)` 收集每个类别的已知实例。类别存在多个实例时，每个实例都可能提供更早的可见证据。
3. `object_visible_frames(obj_id)` 获准时，对每个实例取得升序可见帧列表；对同一类别取所有非空列表中的最小帧槽位，作为当前证据下的类别最早可见时刻。
4. 记录每个类别的最早证据以及此前已经检查的帧范围。工具中的首次检出只是当前观测上界，不自动等于真实首次出现。
5. 优先检查会改变选项顺序的早期帧和相邻槽位。若类别疑似漏检，可针对相关冻结帧补检或查看裁剪，并用后续清晰视角核对早期局部外观。
6. 将各类别的先后约束与题目选项逐条比较。同一采样间隔内无法分辨顺序时，不编造亚帧时间，选择最符合现有可见证据的完整合法序列。

## 分支与检查

- `object_visible_frames` 返回空列表表示该实例没有有效可见掩码，不等于该类别在整个视频中从未出现。
- 检测服务故障、未运行或空返回不能证明此前不存在；健康空检出也只约束已检查帧。
- 同类别多个实例按最早可见语义聚合，不能只查看任意一个默认实例。
- 重复占位图、缺失帧和派生裁剪不能被当作新的真实时间点。
- 相对出现顺序不依赖三维几何、世界系或米制尺度，这些能力缺失不应阻塞视觉排序。
- 提交前检查类别覆盖、帧槽位顺序和完整选项映射，不捏造冻结集合之外的观察。
