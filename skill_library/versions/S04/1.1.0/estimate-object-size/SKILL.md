# 对象最长尺寸估计

## 方法

1. 从题面确定目标实例和待测对象范围。规范任务要求完整对象长、宽、高中的最大值，不是像素长度、体积或某个醒目部件。
2. 选择能展示整体轮廓和主轴的原图，核查遮挡、截断、附件以及同类多实例；需要时先完成目标实例消歧。
3. 米制几何获准时，调用 `object_3d_extent(obj_id)`。检查 `extent_metric` 是否为三个有限非负边长，并读取 `n_valid_points` 和 `degradation_flags`。
4. 取 `extent_metric` 的最大值作为最长边；返回中存在 `extent_longest_metric` 时与它交叉核对。工具返回单位是米；题目要求厘米时乘以 100，不能重复乘尺度或重复换算。
5. 若使用了 `bbox_fallback_no_pointcloud` 或点集仅覆盖可见部分，应结合原图判断轴对齐框高估、旋转物体、局部点云低估和附件遗漏风险。
6. 工具测量不可用时，先判断哪一维最长，再利用完整视角、相近深度参照物和类别尺寸范围进行视觉估计，输出最有依据的单一数值。

## 分支与检查

- 缺少有效尺度、几何或对象绑定时不得调用米制尺寸工具，也不能从图像猜一个尺度写回工具路径。
- `extent_metric` 是三元素列表，不能把整个列表提交为答案；应选择其中最大有限值。
- 只有局部轮廓或点云时，不能把可见部分尺寸宣称为完整对象精确尺寸。
- 轴对齐包围盒可能高估旋转物体，局部表面可能低估完整尺寸；应结合 `degradation_flags` 和原图解释。
- 类别常识只能提供估计范围，不能使用固定类别常量替代当前场景判断。
- 提交前检查目标身份、最长维选择以及米到厘米的单次换算。
