# 房间边界与面积估计

## 方法

1. 从题面确定待估计的是单个房间、连通区域还是多个空间的合并范围。利用门洞、墙面、转角和相机移动区分空间，同一区域的重复拍摄只计算一次。
2. 根据原图和场景摘要检查地面、墙面及边界覆盖。家具遮挡的地面不等于缺失面积，地板像素数、墙面面积和房间对角线也不等于所问面积。
3. 米制平面工具获准时，调用 `plane_fit_room_size()`，读取 `room_area_m2`、`room_diagonal_normalized`、`plane_inlier_ratio`、`fit_quality` 和 `degradation_flags`。
4. `room_area_m2` 已经是平方米，直接作为面积候选，不要再次乘尺度或平方换算。`fit_quality` 是审计信息，不应脱离冻结门限自行充当拒答条件。
5. 核对工具拟合覆盖是否与题面空间一致。非矩形或多区域场景应按有依据的区域分解与并集理解，避免用外接矩形或凸包填满凹口、门外空间和区域间隔。
6. 平面测量不可用时，从多个原图视角建立简化平面布局，利用墙段、门洞和相近深度的尺寸参照估计主尺寸，再按有依据的区域组合计算面积。
7. 检查未观察边界、重复区域和空间范围是否主导误差，最终输出最有依据的有限正平方米数值。

## 分支与检查

- 缺少有效尺度、点云或米制授权时不得调用 `plane_fit_room_size`，也不能把归一化面积冒充平方米。
- 工具失败、无效数值或结果失效不能解释为零面积；应转入视觉布局估计。
- `room_area_m2` 已完成面积尺度换算，不能再次乘尺度平方。
- 家具遮挡不会自动扣除房间面积；重复拍摄和重叠区域不能重复相加。
- 多房间合并必须符合题面范围，不能因为画面中可见相邻空间就擅自扩大边界。
- 提交前检查空间范围、平方米单位和测量或视觉依据是否一致。
