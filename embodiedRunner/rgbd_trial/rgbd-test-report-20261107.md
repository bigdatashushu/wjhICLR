# Navigation 同步 RGB-D 首次试验

实现与模型输入核验通过。完成 5/5 题，所有 26 次模型请求均按顺序输入当前 RGB 与同一仿真事件的深度图。两图均为 500×500。

本轮 RGB-D 成功 4/5；已有 RGB 基线成功 4/5。模型请求分别为 26 与 25 次。

成功题仍为 000、001、002、004；003 在 20 步上限结束时未完成目标。原基线 003 因无效计划提前结束；本轮该题执行到了官方步数上限，仍没有转化为成功。

五题均与已有基线对应相同官方问题和指令，但首帧 RGB 哈希一致的只有 0/5 题。基线 000–002 来自历史 GPU 3 运行，本次使用 GPU 7；不能将哈希不同的图像当作完全相同的初始视觉输入。这轮验证同步双图输入可运行，成绩变化仍需结合配对限制理解。

同题抓图验收与正式运行的两次重置也出现了轻微首帧变化：RGB 平均每通道绝对差为 0.157（8 位强度），深度平均绝对差约 1.99e-8 米，最大差约 0.00237 米。这是跨重置比较，与单次事件内 RGB/深度同步的核验分别记录。
