# 逐轮快照接入：实施与上下文预算

2026-11-05。用户已批准实施“逐轮快照适配”，要求先规划每部分上下文预算。下面的 token 估计指实现 agent 的阅读、推理、编辑和验证上下文，不是在线评测模型请求预算，也不是硬性停止额度。

## 工作块与预算

| 工作块 | 预计上下文 tokens | 具体产物与结束条件 |
|---|---:|---|
| 来源隔离、合同定稿 | 6k–10k | 独立worktree、显式来源manifest、public观察/动作/修订/错误合同；确认三个worker逐step返回观测 |
| 公共执行边界和进程隔离 | 14k–18k | 动作control profile、程序装配/执行、完整方法交付、OS隔离、QA默认合同回归 |
| 宿主FSM、预算与V2桥接 | 14k–18k | 单一env写入口、每step观测、revision/去重/超时停止、三环境adapter、fake端到端 |
| 感知证据、Skill与入口 | 12k–16k | 当前图像局部感知/数值工具、独立方法manifest与三个全文、prompt、CLI及脱敏audit |
| 综合验收与交付 | 12k–16k | offline三环境闭环、状态失效/隔离/预算/交付测试、原基线保护、使用说明和实现报告 |
| 故障定位余量 | 8k–12k | 只在出现实际失败时使用；保留失败证据，不重复宽泛探索 |

预计跨多个上下文完成。每个工作块结束后记录已实现接口、已通过测试、尚未解决问题及下一步；在工具结果已返回的干净边界切换上下文。新上下文只重读当前模块和必要合同，不重新扫描整个项目。预算到达估计值时先压缩稳定结论，不能把未完成工作标为完成。

## 当前实施选择

- 使用独立 `wjhICLR-embodied-architecture` worktree，主项目现有dirty源码及冻结实验保持原身份。
- 绑定主项目已核对HEAD及必要未跟踪任务文件，不复制密钥、socket、旧runs或venv。
- 完整Skill → Python程序 → 独立受限执行/工具 → SubmitActions → 官方宿主step；当前单图，不做跨帧世界重建。
- 每个正常 `env.step` 都返回观测，失败动作也接收ACK中的RGB和反馈。家务 `invalid` 只更新计数、复用旧RGB，不作为真实step。
- 初版明确支持 `single_action` 调度，默认每次只执行已接受计划的第一个动作，然后取新观测重新决策。此为新协议，Direct/B01/B11使用同一调度策略；不把旧九题批计划成绩当新协议配对结果。`official_prefix` 只在其失效边界和共同对比规则验证后作为显式可选策略。
- 先完成本地离线实现和真实OS假输入隔离验收；远端部署、模型/感知请求、仿真smoke仍按既定阶段分别执行授权范围，不复用旧裸模型授权。
- 上一阶段“停止在源码修改前”的限制已由本次实施批准解除；不需要再次申请离线源码、测试和方法正文修改权限。

## 持续交接

隔离worktree内维护 `embodiedRunner/IMPLEMENTATION_STATUS.md`，仅记录模块状态、接口决定和验证摘要，不写凭据、模型正文或GT。临时脚本、pytest缓存、sandbox临时目录放在workspace之外；用户可复核的最终报告和收据放在任务目录。
